ScratchLoginSystem

ホームページに「Scratchアカウントでログイン」を入れるためのツールです。

共同制作：suzunokana × tr3131kami

ライブデモ

実際にログインを試せます。ボタンを押すと認証コードが出るので、認証用プロジェクトにコメントして戻ってきてください。

いまはログインしていません

ログインの流れ

  1. 開発者がホームページに ScratchLoginSystem を搭載します。
  2. ログインボタンを押すと、認証コードとコード送信プロジェクトへのリンクが表示されます。
  3. 利用者は、そのプロジェクトに認証コードをコメントします。
  4. 「完了」を押すと、Scratch の API でコメントを確認し、認証コードが合っているかと、コメントした人のユーザー名を取得します。
  5. ユーザー名が分かればログイン完了です。

ホームページへの入れ方

1. ライブラリを読み込みます。

<script src="https://tr3131kami.github.io/ScratchLoginSystem/scratch-login.js"></script>

2. 初期化します。ログインできたときに呼ばれる処理を書きます。

<script>
  ScratchLogin.init({
    onLogin: function (user) {
      alert(user + " としてログインしました");
    }
  });
</script>

3. ログインボタンを置きます。

<button onclick="ScratchLogin.login()">Scratchでログイン</button>

ログイン中のユーザー名は ScratchLogin.getUser() で取得でき、ログアウトは ScratchLogin.logout() です。認証用プロジェクトは標準で ScratchLoginSystem のものが使われます。自分のプロジェクトに変えたい場合は init に projectId を渡してください。

認証用プロジェクト

認証コードのコメント先は、専用プロジェクト ScratchLoginSystem 認証コード受付 です。コードはログインのたびに変わり、コメントした本人のアカウント名だけが取得されます。パスワードを聞くことはありません。

注意

・この仕組みは静的なホームページ向けの「表示ログイン」です。会員限定の秘密の情報を守るような強い認証ではありません。

・コメントが Scratch に反映されるまで数秒かかることがあります。「完了」を押すと、最大60秒間は自動で再チェックします。

・認証コードには有効な時間（1時間）があります。
